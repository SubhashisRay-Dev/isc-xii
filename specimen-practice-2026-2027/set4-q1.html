LocalMinimum

Question

Each element of a matrix is the elevation of a platform. A Local Minimum Cell is an interior cell whose elevation is strictly lower than its four neighbours (up, down, left, right). Declare a matrix H[ ][ ] of order M × N where 4 ≤ M, N ≤ 9 (check validity, else INVALID INPUT), accept the heights and:

  1. Display the matrix.
  2. Display all local minimum cells and their positions.
  3. Display the smallest local minimum cell (LMC).

Example 1: M=4, N=4, values 8796 6185 9728 5679 → 1 AT (2,2); 2 AT (3,3); SMALLEST LMC = 1.
Example 3: 1234 5678 9876 5432 → NO LOCAL MINIMUM CELL.

Algorithm

  1. Start.
  2. Accept m and n. If either is below 4 or above 9, print INVALID INPUT and stop.
  3. Read the m x n matrix h[][] and display it.
  4. Set small to a very large value and found = false.
  5. For i from 1 to m-2 and j from 1 to n-2 (interior cells only): if h[i][j] is less than all four neighbours, print it with its 1-based position, set found = true and update small if it is smaller.
  6. If found is false print NO LOCAL MINIMUM CELL; otherwise print SMALLEST LMC = small.
  7. Stop.

Variable description

VariableData typeDescription
m, nintNumber of rows and columns
h[][]intMatrix of elevations
smallintSmallest local minimum found so far
foundbooleantrue if at least one local minimum exists
vintValue of the cell being tested
i, jintRow and column loop variables

Program (Java)

import java.util.*;

public class LocalMinimum {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("M = ");
        int m = sc.nextInt();
        System.out.print("N = ");
        int n = sc.nextInt();
        if (m < 4 || m > 9 || n < 4 || n > 9) {
            System.out.println("INVALID INPUT");
            return;
        }

        int h[][] = new int[m][n];
        System.out.println("Enter the numbers:");
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                h[i][j] = sc.nextInt();

        System.out.println("THE MATRIX IS:");
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++)
                System.out.print(h[i][j] + " ");
            System.out.println();
        }

        int small = Integer.MAX_VALUE;
        boolean found = false;
        System.out.println("LOCAL MINIMUM CELL");
        // only interior cells have all four neighbours
        for (int i = 1; i < m - 1; i++)
            for (int j = 1; j < n - 1; j++) {
                int v = h[i][j];
                if (v < h[i - 1][j] && v < h[i + 1][j] && v < h[i][j - 1] && v < h[i][j + 1]) {
                    System.out.println(v + " AT (" + (i + 1) + "," + (j + 1) + ")");  // 1-based position
                    found = true;
                    if (v < small) small = v;       // track the smallest LMC
                }
            }

        if (!found) System.out.println("NO LOCAL MINIMUM CELL");
        else        System.out.println("SMALLEST LMC = " + small);
    }
}
