DateValidator

Question

Accept a date in the format DD/MM/YYYY. Validate it considering the correct number of days in each month and leap year rules. If valid:

  1. Display the number of days remaining in that month.
  2. Find the sum of all digits of DD, MM and YYYY.
  3. If the digit sum is a perfect square display SPECIAL DATE, otherwise REGULAR DATE.

If invalid, display INVALID DATE.

Example 1: 15/08/2023 → DAYS REMAINING: 16, DIGIT SUM = 21, REGULAR DATE.
Example 2: 13/03/2000 → DAYS REMAINING: 18, DIGIT SUM = 9, SPECIAL DATE.
Example 3: 30/02/2023 → INVALID DATE

Algorithm

  1. Start.
  2. Accept the date as a String and split it at '/'. If there are not exactly 3 parts, or a part is not a number, print INVALID DATE and stop.
  3. Convert the parts to integers d, m, y.
  4. Find the days in month m (28 or 29 for February depending on the leap year rule).
  5. If m is outside 1 to 12, y < 1, or d is outside 1 to days-in-month, print INVALID DATE and stop.
  6. Days remaining = days in month - d.
  7. Digit sum = sum of the digits of d, m and y.
  8. Find r = (int) sqrt(sum); if r*r == sum print SPECIAL DATE, else REGULAR DATE.
  9. Stop.

Variable description

VariableData typeDescription
sStringDate entered
p[]StringParts of the date after splitting
d, m, yintDay, month and year
dm[]intDays in each month
remintDays remaining in the month
sumintSum of digits of d, m and y
tintTemporary copy used to extract digits
rintInteger square root of the digit sum

Program (Java)

import java.util.*;

public class DateValidator {
    static boolean isLeap(int y) {           // leap year rule
        return (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
    }

    static int digitSum(int x) {
        int s = 0;
        while (x > 0) {
            s += x % 10;
            x /= 10;
        }
        return s;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter date (DD/MM/YYYY): ");
        String s = sc.next();

        String p[] = s.split("/");
        if (p.length != 3) {
            System.out.println("INVALID DATE");
            return;
        }
        int d, m, y;
        try {
            d = Integer.parseInt(p[0]);
            m = Integer.parseInt(p[1]);
            y = Integer.parseInt(p[2]);
        } catch (NumberFormatException e) {   // a part is not a number
            System.out.println("INVALID DATE");
            return;
        }

        int dm[] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
        if (isLeap(y)) dm[1] = 29;            // February in a leap year

        if (m < 1 || m > 12 || y < 1 || d < 1 || d > dm[m - 1]) {
            System.out.println("INVALID DATE");
            return;
        }

        int rem = dm[m - 1] - d;              // days left in the month
        int sum = digitSum(d) + digitSum(m) + digitSum(y);
        System.out.println("DAYS REMAINING: " + rem);
        System.out.println("DIGIT SUM = " + sum);

        int r = (int) Math.sqrt(sum);         // perfect square test
        System.out.println(r * r == sum ? "SPECIAL DATE" : "REGULAR DATE");
    }
}
