PlayerAnalyzer

Question

A game stores each player's tag and score. Two players form a team when the 3-digit number in their tags is the same. A tag has the form NAME-NUMBER (e.g. PRO-007): uppercase letters, then exactly 3 digits.

Design a class PlayerAnalyzer to accept N players (5 ≤ N ≤ 15), otherwise display INVALID INPUT.

  1. Display "Valid Tag" or "Invalid Tag" for each tag.
  2. Find teams having exactly two valid players and display them with their combined score. If none, display NO COMPLETE TEAMS FOUND.
  3. Display the player(s) with the highest score among valid tags. If no valid tags, display NO VALID TAGS FOUND.

Example 1: N=5, tags PRO-117, ACE-112, MAX-117, ZEN-115, BAD-12; scores 850, 720, 910, 800, 950 → BAD-12 invalid; TEAMS: PRO-117, MAX-117; Combined Score 1760; TOP SCORER: MAX-117 - 910.

Algorithm

  1. Start.
  2. Accept n. If n < 5 or n > 15, print INVALID INPUT and stop.
  3. Accept n tags and n scores.
  4. For each tag, check: exactly one '-', at least one letter before it and all of them uppercase, exactly 3 digits after it. Store the result in ok[i] and print Valid / Invalid Tag.
  5. For every valid tag i not yet processed, count the valid tags j > i having the same 3-digit number (mark them done).
  6. If the count is exactly 2, print the two tags and the sum of their scores. If no team was printed, print NO COMPLETE TEAMS FOUND.
  7. If there is no valid tag, print NO VALID TAGS FOUND and stop.
  8. Find the maximum score max among valid tags; print every valid tag whose score equals max.
  9. Stop.

Variable description

VariableData typeDescription
nintNumber of players
tag[]StringTags of the players
score[]intScores of the players
ok[]booleantrue if the tag at that index is valid
done[]booleantrue if the player is already placed in a group
foundbooleantrue if at least one complete team exists
validCountintNumber of valid tags
cntintNumber of players sharing the same number
mateintIndex of the second player of a team
maxintHighest score among valid tags

Program (Java)

import java.util.*;

public class PlayerAnalyzer {
    int n;
    String tag[];
    int score[];
    boolean ok[];                              // ok[i] = tag i is valid

    void accept() {
        Scanner sc = new Scanner(System.in);
        System.out.print("N = ");
        n = sc.nextInt();
        if (n < 5 || n > 15) {                 // range check
            System.out.println("INVALID INPUT");
            System.exit(0);
        }
        tag = new String[n];
        score = new int[n];
        ok = new boolean[n];
        System.out.println("Enter " + n + " tags:");
        for (int i = 0; i < n; i++) tag[i] = sc.next();
        System.out.println("Enter " + n + " scores:");
        for (int i = 0; i < n; i++) score[i] = sc.nextInt();
    }

    // format NAME-NUMBER : uppercase letters, '-', exactly 3 digits
    boolean isValid(String t) {
        int p = t.indexOf('-');
        if (p < 1 || p != t.lastIndexOf('-')) return false;
        for (int i = 0; i < p; i++)
            if (!Character.isUpperCase(t.charAt(i))) return false;
        String num = t.substring(p + 1);
        if (num.length() != 3) return false;
        for (int i = 0; i < 3; i++)
            if (!Character.isDigit(num.charAt(i))) return false;
        return true;
    }

    String number(String t) {                  // the 3-digit part of a tag
        return t.substring(t.indexOf('-') + 1);
    }

    void analyse() {
        int validCount = 0;
        for (int i = 0; i < n; i++) {          // (a) validate tags
            ok[i] = isValid(tag[i]);
            System.out.println((ok[i] ? "Valid Tag: " : "Invalid Tag: ") + tag[i]);
            if (ok[i]) validCount++;
        }

        boolean done[] = new boolean[n];
        boolean found = false;
        for (int i = 0; i < n; i++) {          // (b) find teams of exactly two
            if (!ok[i] || done[i]) continue;
            int cnt = 1, mate = -1;
            for (int j = i + 1; j < n; j++) {
                if (ok[j] && number(tag[i]).equals(number(tag[j]))) {
                    cnt++;
                    mate = j;
                    done[j] = true;
                }
            }
            if (cnt == 2) {
                found = true;
                System.out.println("TEAMS : " + tag[i] + ", " + tag[mate]);
                System.out.println("Combined Score: " + (score[i] + score[mate]));
            }
        }
        if (!found) System.out.println("TEAMS: NO COMPLETE TEAMS FOUND.");

        if (validCount == 0) {                 // (c) top scorer
            System.out.println("NO VALID TAGS FOUND");
            return;
        }
        int max = Integer.MIN_VALUE;
        for (int i = 0; i < n; i++)
            if (ok[i] && score[i] > max) max = score[i];
        for (int i = 0; i < n; i++)
            if (ok[i] && score[i] == max)
                System.out.println("TOP SCORER: " + tag[i] + " - " + score[i]);
    }

    public static void main(String[] args) {
        PlayerAnalyzer ob = new PlayerAnalyzer();
        ob.accept();
        ob.analyse();
    }
}
