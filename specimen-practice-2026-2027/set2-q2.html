BasinMonitor

Question

A basin code has the format RB followed by exactly 4 digits (e.g. RB4319). Accept a basin code and rainfall readings for N days (5 ≤ N ≤ 20); otherwise show an error message.

  1. Extract the basin number.
  2. Calculate the sum of its digits.
  3. Store the readings; display the highest, lowest and average rainfall.
  4. Count the days on which rainfall exceeds 150 mm.
  5. If the average is greater than 150 mm display FLOOD WARNING GENERATED, else NORMAL CONDITIONS.

Example 1: RB4319, N=6, 180 145 170 155 190 130 → Basin Number 4319, Digit Sum 17, Highest 190, Lowest 130, Average 161.67, Days exceeding 150 mm: 4, FLOOD WARNING GENERATED.
Errors: R4319 → Invalid Basin Code; N=3 → Invalid Number of Days.

Algorithm

  1. Start.
  2. Accept code. If its length is not 6, it does not start with "RB", or any of the last 4 characters is not a digit, print Invalid Basin Code and stop.
  3. Accept n. If n < 5 or n > 20, print Invalid Number of Days and stop.
  4. Convert the last 4 characters to the integer num; find the digit sum ds by repeatedly taking num % 10.
  5. Read the n readings; track sum, hi (largest), lo (smallest) and cnt (readings > 150).
  6. Compute avg = sum / n.
  7. Print all results with the average to 2 decimal places.
  8. If avg > 150 print FLOOD WARNING GENERATED, else NORMAL CONDITIONS.
  9. Stop.

Variable description

VariableData typeDescription
codeStringBasin code entered
okbooleantrue if the code format is correct
nintNumber of days
numintBasin number (4-digit part)

Program (Java)

import java.util.*;

public class BasinMonitor {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Basin Code: ");
        String code = sc.next();

        // format check: RB + exactly 4 digits
        boolean ok = code.length() == 6 && code.startsWith("RB");
        for (int i = 2; ok && i < 6; i++)
            if (!Character.isDigit(code.charAt(i))) ok = false;
        if (!ok) {
            System.out.println("Invalid Basin Code");
            return;
        }

        System.out.print("N: ");
        int n = sc.nextInt();
        if (n < 5 || n > 20) {
            System.out.println("Invalid Number of Days");
            return;
        }

        int num = Integer.parseInt(code.substring(2));   // basin number
        int ds = 0, t = num;
        while (t > 0) {                                  // digit sum
            ds += t % 10;
            t /= 10;
        }

        int r[] = new int[n];
        int sum = 0, cnt = 0;
        System.out.println("Enter " + n + " rainfall readings:");
        for (int i = 0; i < n; i++) r[i] = sc.nextInt();
        int hi = r[0], lo = r[0];
        for (int i = 0; i < n; i++) {
            sum += r[i];
            if (r[i] > hi) hi = r[i];                    // highest
            if (r[i] < lo) lo = r[i];                    // lowest
            if (r[i] > 150) cnt++;                       // days above 150 mm
        }
        double avg = (double) sum / n;                   // cast to avoid integer division

        System.out.println("Basin Number: " + num);
        System.out.println("Digit Sum: " + ds);
        System.out.println("Highest Rainfall: " + hi);
        System.out.println("Lowest Rainfall: " + lo);
        System.out.printf("Average Rainfall: %.2f%n", avg);
        System.out.println("Days exceeding 150 mm: " + cnt);
        System.out.println(avg > 150 ? "FLOOD WARNING GENERATED" : "NORMAL CONDITIONS");
    }
}
