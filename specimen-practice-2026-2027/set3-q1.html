EnrolmentChecker

Question

An enrolment code has the format: 2 uppercase letters + 4-digit year + 3-digit serial number (e.g. SC2026045). Stream letters: SC (Science), CM (Commerce), HM (Humanities). Year: 2024, 2025 or 2026. Serial: 001 to 999.

Design a class to accept codes for 5 to 20 applicants (else INVALID INPUT) and:

  1. Display ACCEPTED if valid; otherwise the reason: Incorrect length, Invalid stream, Invalid year or Invalid serial number.
  2. If only the stream letters are in lowercase (e.g. sc2026045) and the rest is valid, convert and display ACCEPTED AFTER AUTO-CORRECTION.
  3. Count accepted applicants per stream and display the stream(s) with the highest count (all of them on a tie).

Example 1: SC2026045, CM2025012, sc2026075, AB2025015, HM2025000 → Accepted, Accepted, Accepted after auto-correction, Invalid stream, Invalid serial number; SC : 2, CM : 1, HM : 0; Highest Enrolment : SC

Algorithm

  1. Start.
  2. Accept n. If n < 5 or n > 20, print INVALID INPUT and stop.
  3. Accept n codes.
  4. For each code run the checks in order: length must be 9; the first two letters (converted to uppercase) must be SC, CM or HM; characters 3 to 6 must be digits within 2024 to 2026; the last 3 must be digits within 1 to 999. Stop at the first failed check and report its reason.
  5. If all checks pass, increase the count of that stream. Print Accepted, or Accepted after auto-correction if the stream letters were not already uppercase.
  6. Print the count of each stream.
  7. Find the largest count and print every stream having that count.
  8. Stop.

Variable description

VariableData typeDescription
nintNumber of applicants
code[]StringEnrolment codes
streams[]StringValid stream codes SC, CM, HM
cnt[]intAccepted applicants per stream
st, upStringStream letters as typed and in uppercase
kintIndex of the stream in streams[]
yr, srStringYear part and serial part of the code
y, sintYear and serial as numbers
maxintHighest stream count

Program (Java)

import java.util.*;

public class EnrolmentChecker {
    int n;
    String code[];
    String streams[] = {"SC", "CM", "HM"};
    int cnt[] = new int[3];                  // accepted count for each stream

    void accept() {
        Scanner sc = new Scanner(System.in);
        System.out.print("Number of applicants: ");
        n = sc.nextInt();
        if (n < 5 || n > 20) {
            System.out.println("INVALID INPUT");
            System.exit(0);
        }
        code = new String[n];
        System.out.println("Enter the codes:");
        for (int i = 0; i < n; i++) code[i] = sc.next();
    }

    boolean allDigits(String x) {            // true if every character is a digit
        for (int i = 0; i < x.length(); i++)
            if (!Character.isDigit(x.charAt(i))) return false;
        return true;
    }

    // returns the result text for one code and updates the stream count
    String check(String c) {
        if (c.length() != 9) return "Incorrect length";

        String st = c.substring(0, 2);       // stream letters as typed
        String up = st.toUpperCase();        // auto-corrected form
        int k = -1;
        for (int i = 0; i < 3; i++)
            if (streams[i].equals(up)) k = i;
        if (k == -1) return "Invalid stream";

        String yr = c.substring(2, 6);
        if (!allDigits(yr)) return "Invalid year";
        int y = Integer.parseInt(yr);
        if (y < 2024 || y > 2026) return "Invalid year";

        String sr = c.substring(6);
        if (!allDigits(sr)) return "Invalid serial number";
        int s = Integer.parseInt(sr);
        if (s < 1 || s > 999) return "Invalid serial number";

        cnt[k]++;                            // accepted: count it
        return st.equals(up) ? "Accepted" : "Accepted after auto-correction";
    }

    void report() {
        for (int i = 0; i < n; i++)
            System.out.println(code[i] + " : " + check(code[i]));

        System.out.println("Stream Report");
        int max = 0;
        for (int i = 0; i < 3; i++) {
            System.out.println(streams[i] + " : " + cnt[i]);
            if (cnt[i] > max) max = cnt[i];
        }
        if (max == 0) {
            System.out.println("No accepted applicants");
            return;
        }
        System.out.print("Highest Enrolment : ");
        for (int i = 0; i < 3; i++)          // print all streams that tie for the highest
            if (cnt[i] == max) System.out.print(streams[i] + " ");
        System.out.println();
    }

    public static void main(String[] args) {
        EnrolmentChecker ob = new EnrolmentChecker();
        ob.accept();
        ob.report();
    }
}
