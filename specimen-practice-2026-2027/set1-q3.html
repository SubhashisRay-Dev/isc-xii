Delivery Zone Orders

Question

A food-delivery kitchen records orders from delivery zones (rows, 2 ≤ Z ≤ 5) over consecutive days (columns, 5 ≤ D ≤ 15). Store the order counts and:

  • Highest Total Orders: display the zone with the highest total over all days, with its total.
  • High Demand Days: for each zone, display the days on which orders are above that zone's average.
  • Increase in Orders: for each zone, display the days on which orders are higher than the previous day.

Invalid zones → INVALID ZONE; invalid days → INVALID DAYS. If a zone has no such days, display None.

Example 1: 3 zones, 6 days: (4 6 3 7 5 2), (2 3 5 4 6 5), (5 4 6 3 2 4). Zone 1 high-demand days: Day 2, Day 4; increases: Day 2, Day 4.

Note: in the paper's Example 1, the zone totals are 27, 25 and 24, so the program prints Zone 1 : 27 orders. The printed sample (“Zone 2 : 25”) appears to be a typing error in the specimen paper.

Algorithm

  1. Start.
  2. Accept z. If z < 2 or z > 5, print INVALID ZONE and stop.
  3. Accept d. If d < 5 or d > 15, print INVALID DAYS and stop.
  4. Read the z x d matrix a[][].
  5. Compute total[i], the row sum of every zone.
  6. Find the zone with the largest total (first zone in case of a tie) and print it.
  7. For each zone, compute avg = total / d; collect every day j with a[i][j] > avg; print the days or None.
  8. For each zone, collect every day j >= 1 with a[i][j] > a[i][j-1]; print the days or None.
  9. Stop.

Variable description

VariableData typeDescription
zintNumber of zones (rows)
dintNumber of days (columns)
a[][]intOrder count for each zone and day
total[]intTotal orders of each zone
bestintIndex of the zone with the highest total
avgdoubleAverage daily orders of a zone
sStringText list of days built for output
i, jintLoop variables for zone and day

Program (Java)

import java.util.*;

public class DeliveryOrders {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Number of zones: ");
        int z = sc.nextInt();
        if (z < 2 || z > 5) {
            System.out.println("INVALID ZONE");
            return;
        }
        System.out.print("Number of days: ");
        int d = sc.nextInt();
        if (d < 5 || d > 15) {
            System.out.println("INVALID DAYS");
            return;
        }
        int a[][] = new int[z][d];
        int total[] = new int[z];
        for (int i = 0; i < z; i++)
            for (int j = 0; j < d; j++) {
                a[i][j] = sc.nextInt();
                total[i] += a[i][j];           // row total
            }

        // zone with the highest total (strict > keeps the first zone on a tie)
        int best = 0;
        for (int i = 1; i < z; i++)
            if (total[i] > total[best]) best = i;
        System.out.println("Highest Total Orders :");
        System.out.println("   Zone " + (best + 1) + " : " + total[best] + " orders");

        // days above the zone's average
        System.out.println("High Demand Days:");
        for (int i = 0; i < z; i++) {
            double avg = (double) total[i] / d;
            String s = "";
            for (int j = 0; j < d; j++)
                if (a[i][j] > avg)
                    s += (s.equals("") ? "" : ", ") + "Day " + (j + 1);
            if (s.equals("")) s = "None";
            System.out.println("   Zone " + (i + 1) + " : " + s);
        }

        // days where orders rose compared with the previous day
        System.out.println("Increase in Orders:");
        for (int i = 0; i < z; i++) {
            String s = "";
            for (int j = 1; j < d; j++)
                if (a[i][j] > a[i][j - 1])
                    s += (s.equals("") ? "" : ", ") + "Day " + (j + 1);
            if (s.equals("")) s = "None";
            System.out.println("   Zone " + (i + 1) + " : " + s);
        }
    }
}
