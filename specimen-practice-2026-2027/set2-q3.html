SecurityCode

Question

A digital lock generates a security code: a positive integer of 5 to 10 digits. Display INVALID INPUT if it has fewer than 5 or more than 10 digits. Otherwise:

  1. Display the first and last digit.
  2. Calculate the sum of digits at even positions, at odd positions (counted from the left, starting at 1), and the product of all non-zero digits.
  3. Display the frequency of each digit (0-9) that occurs, and the most frequent digit (the smallest digit on a tie).
  4. Classify: STRONG CODE (all digits distinct), MODERATE CODE (only one digit repeated), WEAK CODE (two or more digits repeated).

Example 1: 5834271 → First 5, Last 1, Odd-position sum 11, Even-position sum 19, Product 6720, Most frequent 1, STRONG CODE.
Example 3: 75523755 → Product 183750, Most frequent 5, WEAK CODE.

Algorithm

  1. Start.
  2. Accept the code as a long n; convert it to a String s. If n <= 0 or the length is less than 5 or more than 10, print INVALID INPUT and stop.
  3. Set odd = even = 0, prod = 1, and clear freq[0..9].
  4. For each position i (0 to len-1): digit d = s.charAt(i); if (i+1) is odd add to odd, else to even; if d != 0 multiply prod by d; increase freq[d].
  5. Print the first and last digits, odd, even and prod.
  6. Print every digit whose frequency is above 0. Find the digit with the highest frequency (scan 0 to 9 using strict > so the smallest wins a tie).
  7. Count the digits with freq > 1 into rep.
  8. If rep == 0 STRONG; if rep == 1 MODERATE; otherwise WEAK.
  9. Stop.

Variable description

Program (Java)

import java.util.*;

public class SecurityCode {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter the security code: ");
        long n = sc.nextLong();
        String s = Long.toString(n);
        int len = s.length();
        if (n <= 0 || len < 5 || len > 10) {
            System.out.println("INVALID INPUT");
            return;
        }

        int odd = 0, even = 0;
        long prod = 1;                       // long: product can exceed int range
        int freq[] = new int[10];            // freq[d] = how many times digit d occurs
        for (int i = 0; i < len; i++) {
            int d = s.charAt(i) - '0';
            if ((i + 1) % 2 == 1) odd += d;  // positions are counted from 1
            else                  even += d;
            if (d != 0) prod *= d;           // ignore zeros in the product
            freq[d]++;
        }

        System.out.println("FIRST DIGIT: " + s.charAt(0));
        System.out.println("LAST DIGIT: " + s.charAt(len - 1));
        System.out.println("SUM OF ODD POSITION DIGITS: " + odd);
        System.out.println("SUM OF EVEN POSITION DIGITS: " + even);
        System.out.println("PRODUCT OF NON-ZERO DIGITS: " + prod);

        System.out.println("DIGIT FREQUENCY:");
        int maxD = 0, rep = 0;
        for (int d = 0; d <= 9; d++) {
            if (freq[d] > 0) System.out.println(d + ": " + freq[d]);
            if (freq[d] > freq[maxD]) maxD = d;   // strict > keeps the smallest digit on a tie
            if (freq[d] > 1) rep++;               // number of repeated digits
        }
        System.out.println("MOST FREQUENT DIGIT: " + maxD);

        if (rep == 0)      System.out.println("CLASSIFICATION: STRONG CODE");
        else if (rep == 1) System.out.println("CLASSIFICATION: MODERATE CODE");
        else               System.out.println("CLASSIFICATION: WEAK CODE");
    }
}
