Sample Paper 4 · Question 3

SentenceDate

Question

Accept (a) a sentence terminated by ., ? or ! with words separated by a single blank space, and (b) a date in the format DD/MM/YYYY. Then:

  1. Validate the date and the sentence; display an appropriate error message if invalid.
  2. Count and display the total number of vowels V in the sentence.
  3. Add V days to the given date and display the future date.
  4. Sort the words in ascending order of length (equal lengths keep their original order) and display them.

Example 1: The sun is bright today. / 20/01/2024 → NUMBER OF VOWELS = 6; FUTURE DATE (AFTER 6 DAYS): 26/01/2024; SORTED WORDS BY LENGTH: is The sun today bright.
Example 3: date 31/04/2024 → INVALID DATE.

Algorithm

  1. Start.
  2. Accept the sentence sen and the date dt.
  3. Check the sentence ends with '.', '?' or '!'; otherwise print INVALID SENTENCE and stop.
  4. Split dt at '/', convert to d, m, y and check the date using days-in-month and the leap year rule; if invalid print INVALID DATE and stop.
  5. Count the vowels (a, e, i, o, u in either case) in sen into v; print it.
  6. Repeat v times: d = d + 1; if d exceeds the days in month m, set d = 1, m = m + 1; if m > 12, set m = 1, y = y + 1.
  7. Print the future date as DD/MM/YYYY.
  8. Remove the last character of the sentence and split it into words.
  9. Sort the words by length using insertion sort, moving a word only past strictly longer words so equal lengths stay in order.
  10. Print the sorted words.
  11. Stop.

Variable description

VariableData typeDescription
senStringSentence entered
dtStringDate entered as DD/MM/YYYY
d, m, yintDay, month and year
vintNumber of vowels in the sentence
w[]StringWords of the sentence
keyStringWord being inserted during sorting
i, jintLoop variables
chcharCharacter being examined

Program (Java)

import java.util.*;

public class SentenceDate {
    static boolean isLeap(int y) {
        return (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
    }

    static int daysIn(int m, int y) {         // number of days in month m of year y
        int dm[] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
        if (isLeap(y)) dm[1] = 29;
        return dm[m - 1];
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Sentence: ");
        String sen = sc.nextLine().trim();
        System.out.print("Date: ");
        String dt = sc.nextLine().trim();

        // (a) validate the sentence
        int len = sen.length();
        char last = (len > 0) ? sen.charAt(len - 1) : ' ';
        if (last != '.' && last != '?' && last != '!') {
            System.out.println("INVALID SENTENCE");
            return;
        }

        // (a) validate the date
        String p[] = dt.split("/");
        int d = 0, m = 0, y = 0;
        boolean ok = (p.length == 3);
        if (ok) {
            try {
                d = Integer.parseInt(p[0]);
                m = Integer.parseInt(p[1]);
                y = Integer.parseInt(p[2]);
            } catch (NumberFormatException e) {
                ok = false;
            }
        }
        if (!ok || m < 1 || m > 12 || y < 1 || d < 1 || d > daysIn(m, y)) {
            System.out.println("INVALID DATE");
            return;
        }

        // (b) count vowels
        int v = 0;
        for (int i = 0; i < len; i++) {
            char ch = sen.charAt(i);
            if ("aeiouAEIOU".indexOf(ch) != -1) v++;
        }
        System.out.println("NUMBER OF VOWELS = " + v);

        // (c) add v days, one day at a time
        for (int i = 0; i < v; i++) {
            d++;
            if (d > daysIn(m, y)) {           // move to the next month
                d = 1;
                m++;
                if (m > 12) {                 // move to the next year
                    m = 1;
                    y++;
                }
            }
        }
        System.out.println("FUTURE DATE (AFTER " + v + " DAYS): "
                + String.format("%02d/%02d/%04d", d, m, y));

        // (d) insertion sort of words by length (stable)
        String w[] = sen.substring(0, len - 1).split(" ");
        for (int i = 1; i < w.length; i++) {
            String key = w[i];
            int j = i - 1;
            while (j >= 0 && w[j].length() > key.length()) {   // strict > keeps equal lengths in order
                w[j + 1] = w[j];
                j--;
            }
            w[j + 1] = key;
        }

        // (e) display
        System.out.println("SORTED WORDS BY LENGTH:");
        for (int i = 0; i < w.length; i++)
            System.out.print(w[i] + " ");
        System.out.println();
    }
}
