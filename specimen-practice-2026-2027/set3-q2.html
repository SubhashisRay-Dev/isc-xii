ImageEditor

Question

A grayscale image has pixel values from 0 to 255. Design a class ImageEditor to accept an image of size rows × cols (3 ≤ rows, cols ≤ 6), else INVALID INPUT.

  1. Brighten: accept a brightness value b and add it to every pixel; a result above 255 is stored as 255. Store the brightened image separately and display both images.
  2. Bright spot: a pixel greater than all its immediate neighbours (above, below, left, right). A missing boundary neighbour counts as 0. Display the position and value of every bright spot.

Example 1: 4×3 image (250 5 3 / 6 4 7 / 1 9 5 / 4 2 240), b = 20 → brightened: 255 25 23 / 26 24 27 / 21 29 25 / 24 22 255; bright spots: (1,1)=250, (2,3)=7, (3,2)=9, (4,3)=240.

Algorithm

  1. Start.
  2. Accept r and c. If either is below 3 or above 6, print INVALID INPUT and stop.
  3. Read the image into img[][] and the brightness value b.
  4. For every pixel, bright[i][j] = img[i][j] + b; if it exceeds 255 store 255.
  5. Print the original and the brightened image.
  6. For every pixel find the four neighbours; use 0 for any neighbour outside the array.
  7. If the pixel is greater than all four neighbours, print its row, column and value (1-based).
  8. Stop.

Variable description

VariableData typeDescription
r, cintNumber of rows and columns
img[][]intOriginal image
bright[][]intBrightened image
bintBrightness value to add
up, down, left, rightintNeighbour values (0 at the boundary)
vintValue of the pixel being tested
i, jintRow and column loop variables

Program (Java)

import java.util.*;

public class ImageEditor {
    int r, c, img[][], bright[][];

    void accept() {
        Scanner sc = new Scanner(System.in);
        System.out.print("Rows: ");
        r = sc.nextInt();
        System.out.print("Columns: ");
        c = sc.nextInt();
        if (r < 3 || r > 6 || c < 3 || c > 6) {
            System.out.println("INVALID INPUT");
            System.exit(0);
        }
        img = new int[r][c];
        bright = new int[r][c];
        System.out.println("Enter the pixel values:");
        for (int i = 0; i < r; i++)
            for (int j = 0; j < c; j++)
                img[i][j] = sc.nextInt();
    }

    void brighten(int b) {
        for (int i = 0; i < r; i++)
            for (int j = 0; j < c; j++) {
                bright[i][j] = img[i][j] + b;
                if (bright[i][j] > 255) bright[i][j] = 255;   // pixel limit
            }
    }

    void show(int a[][], String title) {
        System.out.println(title);
        for (int i = 0; i < r; i++) {
            for (int j = 0; j < c; j++)
                System.out.print(a[i][j] + "\t");
            System.out.println();
        }
    }

    void brightSpots() {
        System.out.println("Bright Spots");
        for (int i = 0; i < r; i++)
            for (int j = 0; j < c; j++) {
                int v = img[i][j];
                // a missing neighbour outside the image is taken as 0
                int up    = (i > 0)     ? img[i - 1][j] : 0;
                int down  = (i < r - 1) ? img[i + 1][j] : 0;
                int left  = (j > 0)     ? img[i][j - 1] : 0;
                int right = (j < c - 1) ? img[i][j + 1] : 0;
                if (v > up && v > down && v > left && v > right)
                    System.out.println("Row " + (i + 1) + ", Column " + (j + 1) + ", Value = " + v);
            }
    }

    public static void main(String[] args) {
        ImageEditor ob = new ImageEditor();
        ob.accept();
        Scanner sc = new Scanner(System.in);
        System.out.print("Brightness value: ");
        int b = sc.nextInt();
        ob.brighten(b);
        ob.show(ob.img, "Original Image:");
        ob.show(ob.bright, "Brightened Image:");
        ob.brightSpots();
    }
}
