AccountVerifier

Question

A bank performs a few checks on an account number before accepting it. Design a class AccountVerifier to accept one 10-digit account number and:

  • Check that it has exactly 10 digits. If not, display INVALID FORMAT and stop.
  • Starting from the right, double every second digit and leave the others unchanged. If a doubled value is greater than 9, subtract 9 from it. Add the resulting digits. If the total is divisible by 10, display Checksum Valid; otherwise Checksum Invalid.
  • Add the original digits repeatedly until a single digit remains (the Digital Root). Display Root: Odd or Root: Even.

Example 1: 1000000016 → Checksum Valid, Digital Root 8 (Root Even)
Example 2: 4388576018 → Checksum Invalid (total 47), Digital Root 5 (Root Odd)
Example 3: 123456789 → INVALID FORMAT

Algorithm

  1. Start.
  2. Accept the account number as a String acc.
  3. If length of acc is not 10 or any character is not a digit, print INVALID FORMAT and stop.
  4. Set sum = 0, orig = 0.
  5. Repeat for i from 9 down to 0 (right to left): extract digit d; add d to orig.
  6. If (9 - i) is odd (every second digit from the right): d = d * 2; if d > 9, d = d - 9.
  7. Add d to sum.
  8. If sum % 10 == 0 print Checksum Valid, otherwise Checksum Invalid.
  9. While orig > 9: replace orig by the sum of its digits.
  10. If orig is even print Root Even, otherwise Root Odd.
  11. Stop.

Variable description

VariableData typeDescription
accStringAccount number entered by the user
sumintChecksum total after doubling every second digit
origintSum of original digits; reduced to the digital root
iintLoop index (position in the string)
dintCurrent digit
tintTemporary sum while reducing to a single digit

Program (Java)

import java.util.*;

public class AccountVerifier {
    String acc;                              // account number

    void accept() {
        Scanner sc = new Scanner(System.in);
        System.out.print("Account Number: ");
        acc = sc.next();
    }

    // true only if the number has exactly 10 characters and all are digits
    boolean isValidFormat() {
        if (acc.length() != 10) return false;
        for (int i = 0; i < 10; i++)
            if (!Character.isDigit(acc.charAt(i))) return false;
        return true;
    }

    void process() {
        if (!isValidFormat()) {
            System.out.println("INVALID FORMAT");
            return;
        }
        int sum = 0, orig = 0;
        for (int i = 9; i >= 0; i--) {       // scan from the right
            int d = acc.charAt(i) - '0';     // character to digit
            orig += d;                       // sum of original digits
            if ((9 - i) % 2 == 1) {          // every second digit from the right
                d = d * 2;
                if (d > 9) d = d - 9;
            }
            sum += d;
        }
        System.out.println("Account Number: " + acc);
        System.out.println("Checksum    : " + (sum % 10 == 0 ? "Valid" : "Invalid"));

        // digital root: keep adding digits until one digit remains
        while (orig > 9) {
            int t = 0;
            while (orig > 0) {
                t += orig % 10;
                orig /= 10;
            }
            orig = t;
        }
        System.out.println("Digital Root: " + orig + (orig % 2 == 0 ? " (Root Even)" : " (Root Odd)"));
    }

    public static void main(String[] args) {
        AccountVerifier ob = new AccountVerifier();
        ob.accept();
        ob.process();
    }
}
