Sample Paper 2 · Question 1

PhishingDetector

Question

Accept a message terminated by ., ? or ! only. It may contain only alphabets and single blank spaces between words; the program is case-insensitive. Display INVALID INPUT if the terminator is wrong or any digit/special character is present.

Phishing keywords: ACCOUNT, VERIFY, PASSWORD, LOGIN, BANK, URGENT.

  1. Display all words in uppercase.
  2. Display the total words and the number of phishing keywords.
  3. Classify: SAFE (0 keywords), SUSPICIOUS (1 or 2), PHISHING ALERT (more than 2).
  4. Encrypted message: reverse every phishing keyword, leave other words unchanged.

Example: Verify your account password immediately! → TOTAL WORDS: 5, PHISHING WORDS: 3, PHISHING ALERT, YFIREV YOUR TNUOCCA DROWSSAP IMMEDIATELY

Algorithm

  1. Start.
  2. Accept the message msg and trim it.
  3. If the last character is not '.', '?' or '!', print INVALID INPUT and stop.
  4. Remove the last character to get body. If any character of body is neither a letter nor a space, print INVALID INPUT and stop.
  5. Convert body to uppercase and split it into words.
  6. Print all words, and the total number of words.
  7. For each word, if it matches a keyword, increase ph.
  8. Print ph. If ph == 0 print SAFE; else if ph <= 2 print SUSPICIOUS; else PHISHING ALERT.
  9. Build the encrypted message: reverse each keyword, keep other words, join with single spaces; print it.
  10. Stop.

Program (Java)

import java.util.*;

public class PhishingDetector {
    static String key[] = {"ACCOUNT", "VERIFY", "PASSWORD", "LOGIN", "BANK", "URGENT"};

    static boolean isKey(String w) {           // is w a phishing keyword?
        for (String k : key)
            if (k.equals(w)) return true;
        return false;
    }

    static String reverse(String w) {
        String r = "";
        for (int i = w.length() - 1; i >= 0; i--)
            r += w.charAt(i);
        return r;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter the message:");
        String msg = sc.nextLine().trim();
        int len = msg.length();
        char last = (len > 0) ? msg.charAt(len - 1) : ' ';
        if (last != '.' && last != '?' && last != '!') {   // terminator check
            System.out.println("INVALID INPUT");
            return;
        }
        String body = msg.substring(0, len - 1);
        for (int i = 0; i < body.length(); i++) {          // only letters and spaces allowed
            char c = body.charAt(i);
            if (!Character.isLetter(c) && c != ' ') {
                System.out.println("INVALID INPUT");
                return;
            }
        }

        StringTokenizer st = new StringTokenizer(body.toUpperCase());
        int total = st.countTokens();
        String words[] = new String[total];
        int ph = 0;
        for (int i = 0; i < total; i++) {
            words[i] = st.nextToken();
            if (isKey(words[i])) ph++;                     // count keywords
        }

        System.out.println("WORDS:");
        String enc = "";
        for (int i = 0; i < total; i++) {
            System.out.print(words[i] + " ");
            // reverse the keyword, keep other words unchanged
            enc += (isKey(words[i]) ? reverse(words[i]) : words[i]) + " ";
        }
        System.out.println("\nTOTAL WORDS: " + total);
        System.out.println("PHISHING WORDS: " + ph);
        if (ph == 0)      System.out.println("CLASSIFICATION: SAFE");
        else if (ph <= 2) System.out.println("CLASSIFICATION: SUSPICIOUS");
        else              System.out.println("CLASSIFICATION: PHISHING ALERT");
        System.out.println("ENCRYPTED MESSAGE:");
        System.out.println(enc.trim());
    }
}
